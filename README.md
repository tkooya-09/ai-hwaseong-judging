# AI화성 챌린지 심사집계표 (샘플)

공모전 최종 발표심사의 점수 입력부터 집계·출력까지 한 화면에서 처리하는 단일 HTML 도구입니다.
이 저장소는 **가상 데이터로 채운 샘플**입니다. 작품·발표자·심사위원·점수는 모두 실제와 무관합니다.

## 화면 구성

| 메뉴 | 내용 |
|---|---|
| 01 심사 현황 | 전체 진행률, 심사위원별 제출 현황, 작품별 입력 현황 |
| 02 작품 심사 | 심사위원별 6개 작품 × 5개 항목(각 20점) 입력, 자동 저장 |
| 03 최종 집계 | 시민·공무원 부문별 합계(500점)·평균(100점)·순위, CSV, 결과·서명부 출력(A4 가로 1장) |

## 사용 방법

1. `index.html`을 브라우저로 엽니다. 설치·서버·계정이 필요 없습니다.
2. 처음 열면 심사위원 5명이 제출을 마치고 집계까지 끝난 상태로 보입니다.
3. 왼쪽 ‘입력 담당’에서 심사위원을 바꾸면 해당 위원의 심사표가 열립니다.
4. 운영자 화면에서 ‘수정 허용’을 누르면 그 위원의 점수를 고쳐 다시 제출·집계해 볼 수 있습니다.
5. ‘샘플 데이터 복원’을 누르면 처음 상태로 돌아갑니다.

## 알아둘 점

- 점수는 이 브라우저(localStorage)에만 저장됩니다. 여러 기기 사이에 공유되지 않습니다.
- 집계 방식: 최고·최저점 제외 없이 5명 점수를 모두 합산하며, 동점은 공동순위로 표시합니다.
- 행사에 맞게 쓰려면 `index.html` 안의 `window.EVENT_DATA`(작품·심사위원·평가항목)와 `window.SAMPLE_SCORES`(샘플 점수)를 바꾸면 됩니다.
